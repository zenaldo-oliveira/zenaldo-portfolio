## 🚀 Executando o Projeto

Clone o repositório:

```bash
git clone https://github.com/zenaldo-oliveira/zenaldo-portfolio.git
```

Acesse a pasta:

```bash
cd zenaldo-portfolio
```

Instale as dependências:

```bash
npm install
```

Execute:

```bash
npm run dev
```
